# ROAS ganha cor no número, sem substituir o Sinal

O número do ROAS usa faixas próprias (≤1,29 ruim/vermelho · 1,30–1,59 mediano/amarelo · 1,60–1,99 bom/azul · ≥2 excelente/verde) só na célula numérica, em Criativos e Dashboard. A saúde continua vindo do Sinal (régua + Status + Motivo); o campo interno segue `roas_equivalente` e nunca decide saúde.
